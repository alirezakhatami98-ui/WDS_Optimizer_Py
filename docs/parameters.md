# Parameter Reference

All tunable parameters in WDS Optimizer, with their meaning, default
value, plausible range, and qualitative effect.  The authoritative
source of truth for each parameter is its algorithm's
`ALGORITHM_META["params"]`; this document adds benchmark-specific
guidance and design rationale.

For measured sensitivities and recommended values, see
[sensitivity_analysis.md](sensitivity_analysis.md).  That file is
generated by `scripts/sensitivity_analysis.py` and reflects what we
actually observed on the standard benchmarks.

## Global parameters

Set once per experiment; independent of algorithm.

| Parameter | Default | Range | Effect |
|-----------|---------|-------|--------|
| `NS` | 100 | 4–500 | Population / swarm size.  Larger = more exploration per generation; slower per generation.  The paper heuristic for DE/SADE on a network with D variable pipes is `1D–6D`. |
| `MaxGen` | 500 | 5–5000 | Maximum generations.  With `use_convergence` on (SADE only), this is an upper cap. |
| `n_runs` | 1 | 1–50 | Independent runs per experiment.  More runs = tighter statistics; slower.  For publication-quality comparison, use ≥ 10. |
| `seed` | 1 | ≥ 0 | Experiment seed.  Per-run seeds derive from this deterministically. |
| `constraint_policy` | `deb_prefers` | See policies | How infeasible designs are compared.  `deb_prefers` = Deb (2000) feasibility rules; `fixed_penalty_prefers` = penalty method; `simple_cost_only_prefers` = ignore constraints (diagnostic only). |

## Constraints (SI values, entered in network units)

| Parameter | Typical range | Effect |
|-----------|---------------|--------|
| `Pmin` | 10–50 m | Minimum node pressure.  Higher = more expensive design.  The single most impactful constraint. |
| `Pmax` | 60–150 m | Maximum node pressure.  Rarely active in WDS design (networks rarely over-pressure). |
| `Vmin` | 0–0.5 m/s | Minimum velocity.  Avoid stagnating water.  Rarely enforced in benchmark papers. |
| `Vmax` | 1.5–3.0 m/s | Maximum velocity.  Some benchmarks (e.g. Hanoi) have no feasible solution with Vmax ≤ 2.5 m/s; see each benchmark's README. |

**Note:** enabling `Vmax` on Hanoi makes the problem infeasible —
the optimal design has a few pipes at ~9 m/s.  Reference papers for
Hanoi do not enforce Vmax.

## Algorithm parameters — GA

| Parameter | Default | Range | Effect |
|-----------|---------|-------|--------|
| `ga_pc` | 0.8 | [0, 1] | Crossover probability.  Higher = more recombination; too high can lose good genes. |
| `ga_pm` | 0.03 | [0, 1] | Per-gene mutation probability.  Higher = more exploration; too high = random walk. |
| `ga_sel` | tournament | {tournament, roulette} | Selection scheme.  Tournament: robust to fitness scaling.  Roulette: proportional to fitness; sensitive to outliers. |

**Note:** our GA is a *simple* GA, not the Improved GA of Dandy et
al. (1996).  See [algorithms.md](algorithms.md).  Its benchmark gap
vs Simpson's Simple GA is documented there.

## Algorithm parameters — PSO

| Parameter | Default | Range | Effect |
|-----------|---------|-------|--------|
| `pso_w` | 0.7 | [0, 2] | Inertia weight.  Higher = smoother trajectories; lower = more responsive. |
| `pso_c1` | 1.5 | [0, 3] | Cognitive coefficient (pull toward personal best). |
| `pso_c2` | 1.5 | [0, 3] | Social coefficient (pull toward global best). |

**Note:** our PSO uses constant inertia weight.  Suribabu &
Neelakantan (2006) use a decreasing inertia weight; see
[algorithms.md](algorithms.md).

## Algorithm parameters — DE

| Parameter | Default | Range | Effect |
|-----------|---------|-------|--------|
| `de_f` | 0.5 | [0, 2] | Differential weight.  Scale applied to the difference vector. |
| `de_cr` | 0.3 | [0, 1] | Crossover rate.  Fraction of genes taken from the mutant.  WDS problems are separable (cost = sum of per-pipe costs) so low CR often suits them better than the textbook 0.9. |
| `de_strategy` | rand/1/bin | {rand/1/bin, best/1/bin, current-to-best/1/bin} | Mutation strategy.  rand/1/bin = broad exploration; best/1/bin = exploitative. |

## Algorithm parameters — SADE

Paper-faithful implementation of Zheng, Zecchin & Simpson (2013).
Defaults reflect the paper.

| Parameter | Default | Range | Effect |
|-----------|---------|-------|--------|
| `sade_fmin`, `sade_fmax` | 0.1, 0.9 | [0, 2] | Range for the self-adaptive mutation weight F.  Paper: [0.1, 0.9]. |
| `sade_crmin`, `sade_crmax` | 0.1, 0.9 | [0, 1] | Range for the self-adaptive crossover rate CR.  Paper: [0.1, 0.9]. |
| `sade_conv` | True | {True, False} | Use the paper's Cv < Tol convergence criterion.  If False, always run full MaxGen. |
| `sade_tol` | 1e-6 | 1e-9 to 1e-3 | Cv tolerance.  Paper: 1e-6. |
| `sade_stag` | 300 | 0–10000 | Stagnation safeguard: stop after this many generations without improvement.  0 = off.  **Not in the paper** — added for practicality. |

## Common overrides on standard benchmarks

From our experience running the benchmarks:

| Benchmark | NS | MaxGen | Constraint setup | Notes |
|-----------|-----|--------|------------------|-------|
| Hanoi | 200 | 300–500 | Pmin=30 m only | No Vmax (infeasible). |
| Twoloop | 100 | 200 | Pmin=30 m only | Concedes the optimum in <50 generations for most algorithms. |

For sensitivity-verified recommended values per algorithm, see
[sensitivity_analysis.md](sensitivity_analysis.md).
